# Game Projects

Create each game as a separate PlatformIO project folder here, for example `games/reaction-challenge/`. Start from `../../templates/game/` and keep each game's `platformio.ini` and `src/main.cpp` together. Do not place one game inside another game's folder.

The `main` branch keeps this folder clear for your own projects. See the repository README for instructions on sharing a game or browsing the `community-games` branch.
